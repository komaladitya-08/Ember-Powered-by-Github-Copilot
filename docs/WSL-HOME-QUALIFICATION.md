# Windows WSL Home and saved-draft qualification

The new WSL Home workflow keeps three separate inventories on Windows Server 2022 and 2025: two resource cases, nine source Home cases and one shipped-ZIP Home case. Its literal producer and native-source admission remains closed until the expanded current graph is qualified. A default skipped registration is not acceptance evidence.

The shipped case uses the release executable, unchanged debug fuses, native UIA and ordinary mouse/keyboard input. It configures its synthetic local model through Settings, accepts the ordinary WSL and command consent cards, chooses a project folder and distro, and exercises offline repair, identical checked commands, review/export and a fresh typed continuation. It then exercises explicit public-download opt-in, normal baseline and changed exact-set decisions, offline checks, a fresh continuation decision and Not now. Original Windows source, private canaries, excluded dependency trees, fresh exported receipts, Forget and positive process cleanup are checked. The separate resource/source inventories cover live writers, Stop and revoked ownership.

Saved drafts have a separate Windows workflow and one strict source Home case per image. It uses the real OS keyring, saves a stopped encrypted review, quits and restarts the real app, opens the same ciphertext inertly with no inherited folder grant, imports against fresh source and starts work only from a new typed continuation. It does not depend on a WSL capability or reinterpret a model fixture as a native proof.

Both workflows expose a strict `workflow_call` caller and an always-run aggregate that rejects failed, cancelled or skipped configured leaves. During authoring, pull requests run portable contracts and manual dispatch configures native leaves. Before main merge, the trusted CI caller must require both workflows at the same source commit; manual success alone does not meet that requirement. Existing Node inventories remain unchanged. Neither workflow provides live-account or physical-device acceptance evidence.
