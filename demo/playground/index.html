How Ember shows what it's doing

The flame's colour and motion follow the agent's state. Each mood is driven by an event from the Copilot SDK session or from Ember's own tools.

Renderer: src/overlay/ember (flame, bubble, motion). Canvas 2D only, so it runs on RHEL machines without a GPU. The flame is an original design inspired by the idea of a living fire spirit; it uses no film assets.
